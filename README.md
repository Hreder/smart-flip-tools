# Smart Flip Tools

Лендинг + макет особистого кабінету. Зібрано на React + Vite + Tailwind CSS v4.

## Сторінки

- `/` — головний лендинг
- `/cabinet` — особистий кабінет (поки що макет на мок-даних)

## Як запустити локально (необов'язково)

Потрібен встановлений Node.js (версія 20 або новіша).

```bash
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал (зазвичай http://localhost:5173).

## Публікація на Vercel

1. Заливаєш цю папку в репозиторій на GitHub.
2. На vercel.com тиснеш **Add New → Project → Import** і вибираєш репозиторій.
3. Vercel сам визначить, що це Vite. Нічого не змінюй, тисни **Deploy**.
4. Після збірки відкриваєш **Settings → Domains** і додаєш свій домен.

Файл `vercel.json` уже налаштований так, щоб працювали прямі посилання
(наприклад, /cabinet).
